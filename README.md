# CQBFSolver
A solver to count the number of winning strategies in a given QBF.

# Installation:

Running the toolchain requires the following:
- A C and C++ compiler
- External programs:
  * An installed version of the DepQBF QBF solver
  * An installed version of the QSOLE QBF Equivalence solver
  * It should be possible to invoke these programs at the shell level with the commands "depqbf", "qsole"
