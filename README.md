# CQBFSolver
A solver to count the number of winning strategies in a given QBF.

# Installation:

Running the toolchain requires the following:
- A C and C++ compiler
- A python3 interpreter
- External programs:
  * An installed version of the DepQBF QBF solver
  * It should be possible to invoke this program at the shell level with the command "depqbf"
